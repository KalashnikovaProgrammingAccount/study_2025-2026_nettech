Задача 1. Сеть 172.16.20.0/24

Дано: 172.16.20.0/24. Нужно разбить на 3 подсети с максимумом узлов 126, 62 и 62

Характеристики исходной сети

  • Префикс: 24
  • Маска: 255.255.255.0
  • Broadcast: 172.16.20.255
  • Число подсетей: 2^6 = 64
  • Диапазон узлов: 172.16.20.1 – 172.16.20.254

Подсеть 1 (до 126 узлов)

  • Адрес сети: 172.16.20.0/25
  • Маска: 255.255.255.128
  • Диапазон узлов: 172.16.20.1 – 172.16.20.126
  • Broadcast: 172.16.20.127

Для 126 узлов нужна подсеть на 128 адресов = 2^7, значит маска = 25

Подсеть 2 (до 62 узлов)

  • Адрес сети: 172.16.20.128/26
  • Маска: 255.255.255.192
  • Диапазон узлов: 172.16.20.129 – 172.16.20.190
  • Broadcast: 172.16.20.191

Для 62 узлов нужна подсеть на 64 адреса = 2^6, значит маска = 26

Подсеть 3 (до 62 узлов)

  • Адрес сети: 172.16.20.192/26
  • Маска: 255.255.255.192
  • Диапазон узлов: 172.16.20.193 – 172.16.20.254
  • Broadcast: 172.16.20.255

Та же логика, что и во второй подсети, но адрес сети начинается с .192

Задача 4. Сеть 2001:db8:c0de::/48

Дано: 2001:db8:c0de::/48. Нужно разбить на 2 подсети двумя способами

Характеристики исходной сети

  • Тип: зарезервирован для документации и примеров
  • Префикс: 48
  • Маска: FFFF:FFFF:FFFF:0000:0000:0000:0000:0000
  • Диапазон устройств: 2001:db8:c0de:: – 2001:db8:c0de:ffff:ffff:ffff:ffff:ffff

Разбиение по ID подсети

  • 2001:db8:c0de:0001::/64
  • 2001:db8:c0de:0002::/64

Используются биты с 49 по 64, маска расширяется до /64

Разбиение по ID интерфейса

  • 2001:db8:c0de:0000:1000::/68
  • 2001:db8:c0de:0000:2000::/68

Отрезаем полубайт (4 бита) от адреса узла, маска сдвигается с /64 на /68

Задача 5. Сеть 2a02:6b8::/64

Дано: 2a02:6b8::/64. Нужно разбить на 2 подсети двумя способами

Характеристики исходной сети

  • Тип: глобальный
  • Префикс: 64
  • Маска: FFFF:FFFF:FFFF:FFFF:0000:0000:0000:0000
  • Диапазон устройств: 2a02:6b8:: – 2a02:6b8:0000:0000:ffff:ffff:ffff:ffff

Разбиение по ID подсети

  • 2a02:6b8:0000:0001::/64
  • 2a02:6b8:0000:0002::/64

Используем биты с 49 по 64, зарезервированные под подсети

Разбиение по ID интерфейса

  • 2a02:6b8:0000:0000:1000::/68
  • 2a02:6b8:0000:0000:2000::/68

Отрезаем 4 бита от адреса узла, маска сдвигается с /64 до /68
